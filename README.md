# Netflix System Architecture Project

## Project Overview
This is a Database Systems project replicating Netflix's architecture for ENSIASD DEIS program.

## Technologies Used
- PostgreSQL (Relational Database)
- MongoDB (NoSQL Database)
- Redis (Caching)
- Python (Data Generation)
- Node.js (Frontend)
